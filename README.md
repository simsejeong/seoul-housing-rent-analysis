# 서울시 전/월세 임대시장 분석 및 거주 전략 추천 시스템

## 프로젝트 소개
이사를 준비하면서, 특정 지역을 먼저 정하기 보단 내 예산 기준으로 거주 가능한 지역을 찾고 싶었습니다.
하지만 단순히 집값이 저렴한 곳이 아닌 치안이 괜찮고 방이 넓고 방 갯수가 충분하며,
지하와 1층, 옥탑은 피하고 생활 편의시설 접근성이 좋은 매물을 찾고 싶었습니다.

그러나 실제 부동산 플랫폼에서는 조건별 지역 비교가 어렵고, 동네별 평균 월세와 전세가가 얼마인지 파악하기 쉽지 않았고,
예산 기준으로 가능한 지역을 한 눈에 보기 어려웠으며, 시세보다 상대적으로 저렴한 매물이 많은 동네를 파악하기 어려웠습니다.

이를 해결하기 위해 서울시 전/월세 데이터를 기반으로, 지역별 가격 구조를 분석하고
면적, 주택유형, 층 조건 등을 반영하여 저평가 매물 탐색 및 예산 기반 의사결정을 지원하는 데이터 분석 프로젝트를 진행하였습니다.


## 프로젝트 목표
본 프로젝트는 다음과 같은 질문에서 시작되었습니다.

Q. 내 예산으로 갈 수 잇는 지역은 어디인가?
Q. 서울에서 상대적으로 저렴한 동네는 어디인가?
Q. 저평가 매물이 자주 나타나는 지역은 어디인가?
Q. 조건을 유지하려면 필요한 예산은 어느 정도인가?
Q. 월세와 전세 중 어떤 선택이 더 현실적인가?

이를 바탕으로, 조건별 전/월세 시장 구조를 탐색하고, 지역별 가격을 비교하고,
저평가 매물이 많이 나타나는 지역을 찾고, 예산 기반 거주 가능 여부를 판단할 수 있는 데이터 기반 의사결정 대시보드를 구축하고자 하였습니다.


## 사용 데이터
서울시 전월세 실거래 데이터 2023~2025
출처: 국토교통부 실거래가 공개시스템

주요 컬럼
- 구 : 자치구
- 동 : 행정동
- 면적 : 전용면적
- 층 : 건물 층수
- 건물나이 : 준공 후 경과 연수
- 주택유형 : 아파트/ 오피스텔/ 연립다세대/ 단독다가구
- 월세 : 월 임대료
- 보증금 : 월세 보증금
- 전세가 : 전세 보증금


## 프로젝트 진행 과정
1. 데이터 정제 및 전처리
- 결측치 처리
- 이상치 제거
- 컬럼 정리
- 범주형 변수 정규화
- 파생 변수 생성 (면적구간, 층구간, 건물 나이 그룹, 지역별 요약 테이블)

2. EDA
- 전/월세 시장 구조 분석
  - 주택유형별 가격 차이
  - 지역별 가격 분포
  - 면적 대비 가격 차이
  - 층수에 따른 가격 변화

- 지역별 특징 분석
  - 특정 지역의 평균 가격
  - 저평가 매물 비율
  - 월세와 전세 시장 비교

- Feature Engineering
  - 면적구간
  - 층구간
  - 건물나이
  
  +) 건물나이에 따른 가격 분포를 분석한 결과, 신축이라고 항상 비싸거나 구축이라고 항상 저렴한 것은 아닌 경향이 나타났습니다.
  특히, 동일한 건물 연식에서도 동별 가격 차이가 크게 발생하였으며, 
  이는 단순 연식보다는 강남 VS 비강남 등 위치의 영향이 가격 결정에 중요하게 작용한다고 판단하였습니다.
  이를 반영하기 위해 위도·경도 좌표 데이터를 추가하여 지역 기반 가격 분포와 공간적 특성을 함께 분석하였습니다.
  
3. Modeling
- 모델 목적 : 월세, 보증금, 전세가 등 가격 예측
- 사용 모델 : LightGBM, Linear Regression
- 입력 변수 : 구, 동, 면적, 건물나이, 층, 주택유형
- 예측 결과 활용 : 지역별 평균 가격 계산, 잔차(실제값 - 예측값), 저평가 여부 판단

- 월세 VS 전세 비용 비교

- 전/월세 가능 여부 판단
- 거주 전략 추천
